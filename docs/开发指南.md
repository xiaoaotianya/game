# 开发指南

## 常用命令

```bash
npm run dev       # 开发（--host 已开启，手机连同一网络可访问终端里显示的 Network 地址）
npm run build     # 类型检查 + 生产构建，产物在 dist/
npm run preview   # 预览生产构建（含 PWA）
```

## 目录

```
src/
  sdk/          公共能力：types（模块契约）、settings、voice、audio、dom（拖拽/飞入/特效）、progress（记录+自适应难度）
  shell/        平台外壳：首页 / 板块页 / 活动容器 / 家长锁 / 家长面板 / 休息页 / 时长
  modules/      玩法模块，每个一个目录；registry.ts 注册
  content/      内容包 packs/、颜色、常用短语、板块与活动目录 index.ts
prototype/      最初的原生 JS 原型，仅作参考
```

## 三种扩展方式（由易到难）

### 1. 加一个活动（不写代码）

在 `src/content/index.ts` 的 `activities` 里加一行，选一个已有模块和内容包：

```ts
{ id: 'shadow-fruits', section: 'games', module: 'match-shadow', pack: 'fruits',
  title: { zh: '水果影子', en: 'Fruit Shadows' }, icon: '🍎', color: '#ffe3e3' },
```

### 2. 加一个内容包

在 `src/content/packs/` 新建文件（参考 `animals.ts`），每项包括 `id / emoji / name{zh,en}`，可选 `sound`（叫声）和 `color`（颜色类玩法要用）。然后在 `content/index.ts` 的 `packs` 里注册。

### 3. 加一个新模块（新玩法或新教育板块）

1. 新建 `src/modules/<id>/index.ts`，默认导出一个工厂函数，返回 `ModuleImpl`：

```ts
import type { ModuleImpl } from '@/sdk';
import './style.css';

export default function create(): ModuleImpl {
  return {
    mount(el, sdk, { activity, pack }) {
      // 在 el 里渲染；用 sdk.say / sdk.sfx / sdk.input.draggable / sdk.reward.celebrate …
      // 每轮结束调用 sdk.progress.round({ mistakes })，平台会自动调整 sdk.progress.level()
    },
    unmount() {},  // 可选：释放 Pixi 等外部资源
    hint() {},     // 可选：孩子发呆 8 秒时被调用
  };
}
```

2. 在 `src/modules/registry.ts` 注册 manifest（`skills` 决定学习报告统计哪些能力，`levels` 是难度档数）。
3. 在 `content/index.ts` 加活动；需要新板块就在 `sections` 里加一个。

**模块约定**
- 只通过 `sdk` 发声、计时、存进度，不直接访问外壳；定时器一律用 `sdk.later`（离开时自动清理）
- 样式类名加模块前缀（如 `.g-piano`），通用的 `.tile / .slot / .row / .g-board` 在 `styles/base.css`
- 遵守 `docs/规划.md` 第 4 节「儿童产品设计守则」
- 想用 Vue 写模块也可以：在 `mount` 里用 `createApp(Comp, { sdk }).mount(el)`，在 `unmount` 里卸载

## 自适应难度

`sdk/progress.ts`：连续 2 轮零失误升一级；一轮失误 ≥3 次降一级。等级按活动分别保存在本地。
