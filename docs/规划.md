# 宝宝启蒙乐园 · 产品与技术规划

> 定位：一个**家庭自用、可持续扩展**的 2–3 岁（逐步延伸到 4–5 岁）儿童启蒙平台。
> 不是一个游戏，而是「平台外壳 + 可插拔模块」：游戏只是第一类模块，后面可以接入认知、英语、儿歌、绘本、数学等教育模块。
> 支持手机和平板，横屏竖屏都要能用，界面和语音支持中文、英文和中英双语。

---

## 1. 产品结构

### 1.1 儿童端：三层导航，全程不需要识字

```
首页（板块入口，大图标 + 语音）
 └─ 板块（例如「游戏乐园」）
     └─ 活动（例如「找影子·动物园」）
```

| 板块 | 内容 | 阶段 |
|---|---|---|
| 🎮 游戏乐园 | 益智小游戏：配对、分类、拼图、数数、找不同等 | P0 |
| 🃏 认知卡片 | 动物、水果、交通、身体、颜色等主题闪卡，点一下读中英文 | P1 |
| 🎵 儿歌音乐 | 动物钢琴、节奏敲打、儿歌播放（带动画） | P1 |
| 🎨 创意画板 | 一点就填满的涂色、贴纸场景、自由涂鸦 | P2 |
| 🔤 英语启蒙 | 单词听说、简单指令（touch the red one）、英文儿歌 | P2 |
| 📖 绘本故事 | 有声绘本、可以点击互动的翻页故事 | P2 |
| 🪥 生活习惯 | 刷牙、穿衣、收玩具、睡前流程 | P2 |
| 🔢 数学启蒙 | 数量、大小、多少、排序、简单规律 | P3 |
| 🀄 拼音汉字 | 面向 3 岁以上，先预留位置 | P3+ |

### 1.2 家长端（需要长按解锁）

- 基础设置：语言、语音开关、每日时长、宝宝名字
- **多孩档案**：每个孩子单独记录进度和设置
- **板块开关**：可以关掉暂时不想给孩子玩的板块
- **学习报告**：玩了什么、每项能力的练习情况（能力雷达图）、每天的时长
- **自定义内容**：上传家人照片做「这是谁」的认人卡片，或录自己的声音替换系统配音（只存在本地）

## 2. 核心设计：「玩法模板 × 内容包」

这是能不断扩展的关键：**玩法和内容分开**。

- **玩法模板**：配对、分类、数数喂食、点点乐、拼图、闪卡、找不同、排序……每个模板只写一次代码。
- **内容包**：动物园、水果店、交通工具、海洋、颜色、身体部位……每个包是一份 JSON 加素材，包括名字、读音和图片。
- **活动 = 模板 + 内容包 + 难度**。例如 10 个模板乘以 8 个内容包，再乘以 3 档难度，就是几百个活动，而且不用写新代码。

```jsonc
// 一个活动配置示例
{
  "id": "match-zoo-2",
  "template": "match-shadow",
  "pack": "zoo",
  "level": 2,
  "skills": ["cognition", "visual"]
}
```

## 3. 技术架构

```
┌──────────────────────── Shell 平台外壳 ────────────────────────┐
│ 路由/导航 · 家长锁 · 时长管理 · 多孩档案 · 设置 · PWA 离线       │
├──────────────────────── SDK 公共能力 ──────────────────────────┤
│ audio(音效/音乐/配音) · voice(配音优先，TTS 兜底) · i18n        │
│ input(点击/拖拽/吸附) · reward(表扬/庆祝/贴纸) · progress(进度) │
│ storage(本地优先，可接云端) · events(行为记录) · adapt(难度)    │
├──────────────────────── Modules 模块（按需懒加载）─────────────┤
│ templates/match  templates/sort  templates/count  flashcards   │
│ piano  coloring  stories  english …                            │
├──────────────────────── Content 内容层 ────────────────────────┤
│ packs/zoo  packs/fruit  packs/vehicle …（JSON + 图片 + 音频）   │
└────────────────────────────────────────────────────────────────┘
```

### 3.1 模块契约（接入新模块只需要实现这个接口）

```ts
interface ModuleManifest {
  id: string;
  kind: 'game' | 'course' | 'media' | 'tool';
  section: string;               // 属于哪个板块
  title: { zh: string; en: string };
  icon: string;
  skills: SkillId[];             // 练习哪些能力，用于学习报告
  age: [number, number];         // 适合的月龄范围，例如 [24, 48]
  load: () => Promise<ModuleImpl>; // 懒加载，模块再多首页也不会变慢
}

interface ModuleImpl {
  mount(el: HTMLElement, sdk: SDK, ctx: { activity?: Activity }): void;
  unmount(): void;
  hint?(): void;                 // 孩子发呆时，平台会调用它给提示
}
```

所有模块都**只通过 SDK** 去发声、存数据、发表扬，不直接访问外壳。好处有三个：
- 时长管理、家长锁、静音这些全局规则自动对所有模块生效
- 以后换存储、换配音方案，模块不用改
- 外部的教育内容也能包成一个模块接进来，例如嵌入 iframe 的第三方 H5

### 3.2 技术选型（建议）

| 方面 | 选型 | 理由 |
|---|---|---|
| 框架 | **Vue 3 + TypeScript + Vite** | 和你熟悉的技术栈一致；TS 让模块契约更可靠 |
| PWA | vite-plugin-pwa | 可以添加到桌面、离线玩，适合出门带娃 |
| 普通玩法 | DOM + CSS 动画 | 大部分模板够用，开发快 |
| 重动画玩法 | PixiJS（只在需要的模块里懒加载） | 物理效果、粒子、复杂场景 |
| 音频 | Howler.js | 移动端兼容性好，支持音频精灵 |
| 本地存储 | IndexedDB（Dexie） | 存进度、行为记录、用户上传的照片和录音 |
| 云端（可选，后期） | Supabase 或自建接口 | 多设备同步；storage 抽象层先预留好 |
| 部署 | Cloudflare Pages / Vercel / 自己的服务器（必须 HTTPS） | PWA 和 Service Worker 要求 HTTPS |

### 3.3 能力体系（学习报告依据）

`cognition` 认知、`language` 语言、`english` 英语、`number` 数量、`color-shape` 颜色形状、`fine-motor` 精细动作、`music` 音乐、`creativity` 创造、`habit` 生活习惯

每次活动结束记录一条：`{ activity, skills, duration, attempts, mistakes, level }`。平台根据这些记录自动升降难度，同时汇总成家长报告。

### 3.4 素材与配音管线

- **配音**：浏览器自带的 TTS 在不同手机上音色差别很大。正式版用 TTS 服务（例如讯飞或 Azure）**批量生成 mp3**，按「短语 key」管理；浏览器 TTS 只在缺音频时兜底。家长自己录的声音优先级最高。
- **图片**：原型阶段用 emoji；正式版用 AI 生成统一风格的插画（圆润、柔和、高饱和），输出 SVG 或 WebP。
- 每个内容包里的每一项都包括：`id`、`name{zh,en}`、`image`、`voice{zh,en}`，可选 `sound`（叫声）、`color`、`category`。

### 3.5 目录结构

```
src/
  shell/        # 外壳：路由、首页、板块页、家长端
  sdk/          # 公共能力：audio voice i18n input reward progress storage
  modules/      # 每个模块一个目录 + manifest.ts
    match/  sort/  count/  balloons/  piano/  flashcards/ ...
  content/
    packs/      # zoo/ fruit/ vehicle/ ...（pack.json + 素材）
    activities.ts
  registry.ts   # 汇总所有模块 manifest
public/
  audio/ images/
docs/
```

## 4. 儿童产品设计守则（所有模块必须遵守）

1. 不出现文字按钮，全靠语音和图形引导
2. 点击区域至少 80px，拖放判定放宽 30%，不用双击、长按和多指操作
3. 没有失败、扣分和倒计时；做错了轻轻晃一下，再给语音提示
4. 一局 1–3 分钟，每 3–5 次操作给一次奖励
5. 发呆 8 秒以上，自动给提示
6. 没有广告、外链和支付入口；数据只存在本地
7. 到达时长上限后，用「小动物困了」的方式温和地结束

## 5. 路线图

| 阶段 | 目标 | 交付 |
|---|---|---|
| **P0 平台骨架** | 架子搭对 | Vue+TS 工程、Shell（首页/板块/家长锁/时长/设置）、SDK 核心能力、模块契约；把原型的 5 个游戏迁移成模块；PWA 部署上线 |

| **P2 教育扩展** | 多板块 | 英语启蒙、绘本故事、创意画板、生活习惯；多孩档案；学习报告；自定义照片和录音 |
